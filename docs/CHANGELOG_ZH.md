# 3.1.2-zh.1

基于 Pandoc GUI 3.1.2。导入、导出、设置、处理规则库和使用指南改用简体中文。

打开笔记即可快捷导出 Word、PDF 或网页。导出窗口可以选择保存位置、目录、Word 样式参考文件和前后附加文档。首次缺少 Pandoc 或 PDF 排版组件时，可在转换窗口安装。快捷 PDF 使用内置 Typst 和中文字体。

导入默认保留支持提取的图片。原有模板、引用与文档处理功能可继续使用。

下载发布附件中的 **pandoc-gui-zh.zip**。解压后把里面的 **pandoc-gui-zh** 文件夹放进笔记库的 **.obsidian/plugins**，然后在 Obsidian 的第三方插件设置中启用。需要 Obsidian 1.13.0 或更新版本。
