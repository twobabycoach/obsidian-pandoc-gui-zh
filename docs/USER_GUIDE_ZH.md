# 笔记导出助手使用指南

## 把笔记导出为 Word、PDF 或网页

打开一篇笔记，点左侧的「导出笔记」，也可以在文件列表右键点击笔记。选择格式，点击「开始导出」。默认使用笔记名，存到笔记所在文件夹。要改名或换个地方存，展开「文件名、目录与样式」。

**Word** 适合继续编辑或交稿。可以选择一份现成的 Word 文档来套用样式，也可以在正文前加封面、在正文后加附件。**PDF** 适合分享和打印，第一次用时按窗口提示安装排版组件和中文字体。**网页** 用浏览器打开。

## 把 Word 导入为笔记

点左侧的「把文档导入为笔记」，或在命令面板搜索这条命令。点击「选择文件」，选中 Word 文档，再点击「导入为笔记」。默认把支持提取的图片一起导入。手机和平板可以选择已经放进笔记库的源文件。

## 第一次使用

电脑上会自动查找 Pandoc。找不到时，导入或导出窗口会提供「安装转换组件」按钮。第一次安装需要联网，安装完成后可再次点击导入或导出。也可以通过 [Pandoc 官方安装页](https://pandoc.org/installing.html) 安装完整版，再回到 Obsidian。若电脑装在特殊位置，可在插件设置里选择程序文件。

## 保存自己的排版

在「设置 → 笔记导出助手 → 导出模板」选择「新建模板」。先选输出格式，再设置样式参考文件、目录、引文等选项。下次导出时，展开「文件名、目录与样式」选择这个模板。编写命令只用于自定义命令模板。

内置转换组件可以在手机和平板使用。依赖电脑上的其他程序的模板，例如 LaTeX 排版或部分文档处理规则，需要电脑上有相应程序。文件转换失败时，先看窗口里给出的处理方法。
