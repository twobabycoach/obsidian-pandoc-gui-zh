# 安装笔记导出助手

适用于 Obsidian 1.13.0 或更新版本。中文版在社区插件里显示为「笔记导出助手」。

## 把插件放进笔记库

解压后，在 Finder 中打开你的笔记库根目录，按 **⌘⇧.** 显示隐藏文件。打开 **.obsidian → plugins**，把整个 **pandoc-gui-zh** 文件夹复制进去。若没有 plugins 文件夹，在 .obsidian 里新建一个即可。Windows 可在文件资源管理器的「查看」菜单中勾选「隐藏的项目」。

重启 Obsidian，打开 **设置 → 第三方插件**。如处于安全模式，先允许第三方插件，再启用「笔记导出助手」。

中文版使用独立的插件标识。如果库里已有原版 Pandoc GUI，可以在第三方插件中关闭原版，避免看到两套菜单。原版的模板与配置仍保存在原来的插件文件夹。

## 开始使用

打开一篇笔记，点击左侧的「导出笔记」，选择 **Word、PDF 或网页**，再点「开始导出」。文件默认存到这篇笔记旁边。若要改名、选文件夹、生成目录或套用 Word 样式，展开「文件名、目录与样式」。

点击左侧的「把文档导入为笔记」，选择 Word 等支持的文件即可导入。图片默认随文档导入，并存到该笔记专用的图片文件夹。

如果看到「安装转换组件」或「安装 PDF 组件」，点击按钮并等待完成。首次下载需要联网，组件装好后可在本地转换。快捷 PDF 包含思源黑体，可排版中文。

更多说明可在插件设置的「转换组件 → 使用指南」中查看。
